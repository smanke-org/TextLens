# TextLens

Drive the app with `textlens` (the app binary; `textlens help`). See `.claude/skills/textlens/SKILL.md`. Commands live in
`Sources/TextLens/Agent/AgentCommands.swift`; test them on a Debug build with `APP_STORE=/tmp/<name>`, which starts a
test copy on its own history and settings (Release builds ignore it).
